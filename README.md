# DevOps Microservices

Mikroservisna aplikacija za upravljanje odsustvima, zahtevima i obaveštenjima zaposlenih, razvijena kao projekat iz predmeta DevOps.

Razvoj je počeo kroz feature grane sa direktnim merge-ovima u `main`, a od [PR #1](https://github.com/Ksenija-Mudri-IT15/DevOps-Microservices/pull/1) nadalje sve izmene idu kroz pravi GitHub pull request tok.
